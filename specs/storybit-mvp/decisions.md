# StoryBit MVP — проект решений

Статус: **подготовлено, ожидает утверждения владельцем продукта**. Основание: StoryBit_TZ.md v1.0, §12. До утверждения не считать эти параметры окончательными.

## D-01. Размер и формат бита

- Максимум: 1000 Unicode code points, минимум: 1. Считаются code points после нормализации перевода строк к `\n`; пробельный текст не проходит проверку. В Go проверять `utf8.RuneCountInString` после проверки корректного UTF-8.
- Формат: plain text, без интерпретации Markdown или HTML. При отображении клиент экранирует текст. Переводы строк сохраняются.
- Причина: совпадает с предварительным лимитом и текстовым MVP в ТЗ, исключает неоднозначность рендеринга. Альтернативы для утверждения: 500 code points; ограниченный Markdown.

## D-02. Удаление и история

- Удаление бита из личной библиотеки — логическое скрытие. Исторические версии остаются доступны в опубликованных редакциях и цитатах. Повторное редактирование скрытого бита запрещено.
- Удаление статьи — логическое: исключить из публичного поиска и запретить новое цитирование. Ранее опубликованные редакции, использованные в цитатах, сохраняются как исторические источники и доступны в составе цитирующей статьи с пометкой об удалённом источнике. Публичная страница удалённой статьи возвращает 404.
- Физическое удаление контента и обработка правовых запросов — отдельная процедура вне MVP; потребуется отдельное решение о каскадном влиянии на цитаты.

## Приёмка (EARS)

1. Когда автор создаёт или редактирует бит с 1–1000 Unicode code points, StoryBit сохраняет новую версию бита.
2. Когда текст бита пуст, состоит только из пробелов или превышает 1000 Unicode code points, StoryBit возвращает ошибку валидации без записи версии.
3. Когда автор удаляет бит из библиотеки, StoryBit скрывает его из личного списка и сохраняет опубликованные редакции, ссылающиеся на него.
4. Когда автор удаляет статью, StoryBit удаляет её из публичного поиска и запрещает новые цитаты, сохраняя уже опубликованные цитаты с атрибуцией.
5. Когда пользователь открывает опубликованную редакцию после изменения исходного бита, StoryBit показывает текст версии, закреплённой при публикации.
